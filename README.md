# 📄 SE-veebileht

VibeSpace on veebileht, mis aitab kasutajatel vähendada stressi ning parandada keskendumist, õppimise, töö või puhkamise ajal, erinevate taustahelidega.

## 🧘 Mida leht endast kujutab?

VibeSpace on disainitud võimalikult rahuliku atmosfääri loomiseks. Tee oma valik õpingute või lihtsalt lõõgastumise vahel, pane käima taimer ning lase häältel end üle ujutada.

## Rühmatöö normid
• On kohal rühma kohtumistel ja osaleb aktiivselt.
• Teeb oma osa tööst õigeajaliselt.
• Aitab vajadusel teisi.
• Annab tagasisidet ja on valmis kriitilist tagasisidet vastu võtma
• Tunnustab teiste tööd ja pakutud ideid.
• Selgitab oma mõtteid arusaadavalt.
